CHAPTER 01

新手入门

从打开游戏到站稳脚跟，一步步带你走

30秒看懂：这个游戏到底在玩什么？

你继承了爷爷留下的一座破旧农场，从只有50块钱和一堆杂草开始，通过种地、钓鱼、挖矿、养动物、和村民交朋友，一步步把农场做大。游戏没有终点、没有失败，你想怎么玩就怎么玩。

每天的核心循环就四步：

1起床浇水
照顾作物
2出门赚钱
钓鱼/挖矿
3和村民聊天
提升好感
4凌晨2点前
回家睡觉

记住：这游戏没有"正确玩法"。有人第一年就赚百万，有人每天只钓鱼聊天。按自己的节奏来，开心最重要。

第一周每天干什么？照着做就行

1
第1天 · 安顿下来
清理农场杂草 → 种下全部15个防风草种子并浇水 → 去小镇认识村民 → 2点前睡觉。别想着赚钱，先熟悉操作和地图。
2
第2天 · 开始钓鱼
早上浇水 → 去海边找威利拿鱼竿 → 在河边/海边练钓鱼 → 钓到的鱼先存着别卖（可以吃回体力）。
3
第3天 · 采集+钓鱼
浇水 → 全地图跑一遍捡野货（韭葱、野山葵、黄水仙）→ 继续钓鱼升级 → 攒的钱先留着，别乱花。
4
第4天 · 收第一波菜
防风草成熟了！收获卖掉 → 去皮埃尔商店买土豆种子（性价比高）继续种 → 下午钓鱼或采集。
5
第5天 · 矿洞开放！
收到信件说矿洞开了 → 浇水后去矿洞敲石头挖铜矿 → 下到5-10层就行，别贪深 → 铜矿很值钱。
6
第6天 · 稳定节奏
浇水 → 挖矿或钓鱼二选一 → 记得和遇到的村民说话 → 检查钱够不够升级工具（水壶优先）。
7
第7天 · 复盘+准备
整理背包和箱子 → 看看还差多少钱 → 为第13天复活节做准备（那天能买草莓种子，春天最赚钱的作物）。

1第一天怎么过

  • 先清理农场：用斧头砍树、镐子敲石头，收集木材和石头，至少攒够 50 木材。
  • 种防风草：皮埃尔商店买的 15 个防风草种子当天必须种下，浇水后第二天开始生长。
  • 认识村民：向右走到小镇，和遇到的每个 NPC 对话打招呼，提升初始好感。
  • 别熬夜：凌晨 2 点前必须睡觉，否则会晕倒损失金钱和体力。
  • 翻垃圾桶：小镇的垃圾桶每天可以翻一次，可能找到食物或材料。

2初期赚钱思路

  • 钓鱼是神技：春天去河边/海边钓鱼，鲶鱼和鲷鱼售价不错，钓鱼等级提升后收益更高。
  • 采集野货：每天在地图上捡韭葱、野山葵、黄水仙等，春天的韭葱可以吃也可以卖。
  • 下矿洞：第 5 天矿洞开放，敲石头得矿石和晶石，铜矿早期很值钱。
  • 优先种防风草和土豆：土豆有概率一次结多个，性价比高；花椰菜生长慢但单价高。
  • 攒钱买草莓种子：春 13 日复活节，草莓种子是春天最赚钱的作物，尽量多买。

3体力与时间管理

  • 体力分配：早上体力满时先做重活（挖矿、砍树），下午体力低时浇水、钓鱼。
  • 吃食物回体力：钓到的鱼、采集的野货都可以吃，别浪费钱买体力药。
  • 时间观念：商店下午 5 点关门，医院下午 4 点，注意安排行程。
  • 升级工具：攒钱先升级水壶（浇更多地）和镐子（挖更硬的矿），斧头其次。
  • 建造鸡舍：第一个夏天前建好鸡舍，鸡蛋是稳定的被动收入。

4四季规划要点

  • 春天：种防风草+土豆攒钱，复活节抢草莓种子，开始钓鱼和下矿。
  • 夏天：蓝莓是夏天之王（多次收获），同时种辣椒和啤酒花，开始养动物。
  • 秋天：南瓜（单价高）和蔓越莓（多次收获）并行，攒钱准备温室。
  • 冬天：不能种地，集中下矿、钓鱼、升级工具、和村民刷好感。
  • 第一年目标：解锁温室、修好社区中心或完成 Joja 路线、建好畜棚。

新手黄金建议

不要急着扩张！第一年先把地浇好、鱼钓好、矿挖好。很多新手一上来就种 100 颗作物，结果每天浇水浇到虚脱还赚不到钱。先小面积精耕，有了稳定收入再逐步扩大。另外，每周五和周日在猪车那里可以买到稀有种子和物品，记得去看看。

新手必做 vs 千万别踩坑

一定要做

  • 每天浇水：作物不浇水就不长，这是头等大事
  • 每天和村民说话：好感度解锁剧情和配方，很重要
  • 练钓鱼：初期最赚钱的方式没有之一
  • 攒钱等复活节：春13日的草莓种子是春天印钞机
  • 升级水壶：铜水壶能浇3x3，省一半时间
  • 建箱子分类：东西乱扔后期会疯掉

千万别做

  • 别熬夜到2点后：晕倒会扣钱，第二天还没体力
  • 别一开始就种100颗作物：浇不完还累垮
  • 别把铜矿和铁矿全卖了：后期升级工具要用
  • 别在换季前一天种新作物：第二天直接枯萎
  • 别乱花复活节之前的钱：留着买草莓种子
  • 别跳过节日活动：有独家物品和社交机会

CHAPTER 03

Bug修复

常见问题与解决方案，点击展开查看详情

游戏存档丢失或损坏怎么办？

严重

原因：游戏崩溃、云同步冲突或手动删除可能导致存档损坏。

解决方法：

  1. 找到存档位置：Windows 在 %AppData%\StardewValley\Saves，Mac 在 ~/.config/StardewValley/Saves。
  2. 查看是否有 _old 后缀的备份文件，去掉后缀替换原文件即可恢复。
  3. 如果开启了 Steam 云同步，右键游戏 → 属性 → 通用 → 关闭云同步，再从本地存档启动。
  4. 定期手动备份 Saves 文件夹，这是最保险的做法。

游戏卡顿、掉帧严重

中等

解决方法：

  1. 在游戏选项中关闭「全屏模式」改用窗口化，或反之尝试。
  2. 降低「缩放级别」到 75% 或 50%，减少渲染压力。
  3. 关闭「显示水坑」「显示天气效果」等视觉选项。
  4. 电脑如果有核显和独显，确保游戏使用独显运行（NVIDIA 控制面板 → 管理 3D 设置）。
  5. MOD 装太多也会卡顿，尝试移除不必要的 MOD。

安装 MOD 后游戏闪退

严重

原因：SMAPI 版本不兼容、MOD 之间冲突、MOD 未更新到对应游戏版本。

解决方法：

  1. 确保安装了最新版 SMAPI，且 SMAPI 版本支持当前游戏版本。
  2. 逐个移除 MOD 排查冲突，每次只加一个 MOD 测试。
  3. 查看 SMAPI 控制台的红色错误信息，通常会指出是哪个 MOD 出了问题。
  4. 在 Nexus Mods 上检查每个 MOD 的更新日期和兼容版本。
  5. 使用 SMAPI 的 trace 命令获取详细错误日志。

多人联机无法加入或频繁掉线

中等

解决方法：

  1. 房主和玩家的游戏版本必须完全一致，包括 MOD 版本。
  2. 通过 Steam 好友邀请联机最稳定，尽量不用 IP 直连。
  3. 房主确保网络稳定，关闭 VPN 和代理。
  4. 如果一直「正在连接」，让房主在游戏设置中关闭「启用多人游戏」再重新打开。
  5. 联机时不要安装会修改游戏核心机制的 MOD，容易导致不同步。

作物/物品消失或变成错误物品

中等

原因：通常是 MOD 修改了物品 ID，或游戏版本更新后旧存档的物品数据不匹配。

解决方法：

  1. 如果装了 MOD，先移除所有 MOD 再加载存档，确认是否为 MOD 导致。
  2. 不要在不同版本之间来回切换存档，高版本存档在低版本游戏中可能出问题。
  3. 使用存档编辑器（如 Stardew Save Editor）检查并修复异常物品数据。
  4. 如果是季节切换时作物消失，检查是否跨季节种植（非温室作物换季会枯萎）。

游戏没有声音或音效异常

轻微

解决方法：

  1. 检查游戏内选项 → 音频，确认音量没有被静音。
  2. Windows 系统音量合成器中检查星露谷物语是否被单独静音。
  3. 验证游戏文件完整性（Steam 右键 → 属性 → 已安装文件 → 验证完整性）。
  4. 更新声卡驱动，或切换音频输出设备（耳机/音箱）再切回来。

手机版（iOS/Android）闪退或存档问题

中等

解决方法：

  1. 确保手机系统版本满足游戏最低要求，关闭后台其他应用释放内存。
  2. iOS 用户通过 iCloud 备份存档；Android 用户手动复制 StardewValley 文件夹。
  3. 手机版不支持 MOD，安装 MOD 版可能导致不稳定。
  4. 如果存档无法加载，尝试在主菜单点击「加载」→ 选中存档 → 点击「修复」按钮。
  5. 卸载重装前务必备份存档，否则数据会丢失。
CHAPTER 04

第一年进度自查清单

对照看看你做到了哪些，点击可以勾选（存在浏览器里）

春天目标（第1-28天）

种下全部初始防风草并收获第一波作物
拿到鱼竿，钓鱼等级升到3级以上
矿洞下到40层，攒够铜矿和铁矿
春13日复活节买到草莓种子并种下
水壶升级到铜壶（浇3x3）
认识全部村民并开始送礼（至少2人达到2心）

夏天目标（第29-56天）

种上蓝莓（夏天最赚钱作物）
建好鸡舍，养至少4只鸡
矿洞下到80层，拿到金矿
做出熔炉，开始把矿石炼成锭
夏季末存款达到10000金以上

秋天目标（第57-84天）

种上蔓越莓（全年最赚作物）
建好畜棚，开始养牛/羊
社区中心完成至少2个收集包（或Joja路线购买2个升级）
做出罐头瓶和小桶，开始加工农产品
秋季末存款达到30000金以上

冬天目标（第85-112天）

矿洞下到120层底层，拿到骷髅钥匙
完成社区中心锅炉房收集包解锁温室（或Joja购买温室）
工具全部升级到至少铁级
和至少1个村民达到8心（可以送花谈恋爱）
为第二年准备好上古果种子或杨桃种子（温室种植）

达不到也没关系

这只是参考目标，不是硬性要求。星露谷物语没有时间限制，你可以花两年、三年慢慢玩。重要的是享受过程，而不是赶进度。如果第一年没解锁温室，第二年再做也完全OK。
